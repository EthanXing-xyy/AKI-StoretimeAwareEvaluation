# Step 2: Retrospective Continuous Monitoring

## Purpose

Evaluate the 15 corrected formal models at -72, -60, -48, -36, -24, -12, and 0 hours relative to each reference time without changing any fitted artifact.

## Input

- the fixed subject-level split and 2,168-stay held-out test cohort regenerated by Step 1;
- all 15 Step 1 checkpoints, feature lists, preprocessing artifacts, and validation-selected thresholds;
- `configs/monitoring.yaml` and `configs/paths.yaml`.

## Method

The primary reference uses the upstream matched pseudo-onset method for non-AKI stays; discharge time is retained as a sensitivity reference. Eligibility requires a cutoff inside the ICU stay and at least one observation before the cutoff. The policy prohibits model training, split generation, scaler/imputer fitting, test-set threshold tuning, and substitution of non-formal checkpoints.

## Run

After Step 1 has regenerated the local cohort, processed inputs, and static predictions:

```powershell
python Step2_Continuous_Monitoring/scripts/run_monitoring.py --stage dry-run
python Step2_Continuous_Monitoring/scripts/run_monitoring.py --stage full
```

For lower peak memory, run one model/horizon pair per process, then execute:

```powershell
python Step2_Continuous_Monitoring/scripts/merge_monitoring_runs.py
python Step2_Continuous_Monitoring/scripts/run_upstream_analyses.py
python Step2_Continuous_Monitoring/scripts/make_figures_and_summary.py
```

## Output

- `metrics/`: aggregate monitoring and model-integrity checks;
- `figures/`: validated monitoring figures;
- `summary/`: alert burden, clinical faithfulness, time-slice validation, rankings, and the narrative summary;
- patient-level predictions under ignored `work/` paths only.

## Validation

The dry-run and full adapter gates verify checkpoint hashes, cohort identity, feature encoding, static prediction replay, absence of post-cutoff events, unchanged parameters/artifact files, and complete requested-timepoint coverage. Step 1 can also be hashed before and after evaluation:

```powershell
python Step2_Continuous_Monitoring/scripts/baseline_integrity.py snapshot --label before
python Step2_Continuous_Monitoring/scripts/baseline_integrity.py snapshot --label after
python Step2_Continuous_Monitoring/scripts/baseline_integrity.py compare --before before --after after
```

## Notes

No model, preprocessing object, threshold, split, or cohort is fitted or selected in this step.
